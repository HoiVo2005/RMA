## 7️⃣ LINK TẢI TỪ WIKIMEDIA/WIKIPEDIA

### Cách Tìm Ảnh:

1. **Logo Đội Bóng**: `https://commons.wikimedia.org/wiki/Category:Sports_logos`
2. **Huy Chương/Cúp**: `https://commons.wikimedia.org/wiki/Category:Sports_trophies`
3. **Ảnh Cầu Thủ**: `https://commons.wikimedia.org/wiki/Category:Football_players` hoặc tên cầu thủ trực tiếp

### Format URL Chuẩn:

- Wikimedia Commons: `https://upload.wikimedia.org/wikipedia/commons/...`
- Wikipedia Commons: `https://commons.wikimedia.org/wiki/...`
- Thiết lập `width` query param để resize: `?w=400` (Wikimedia hỗ trợ)

## 8️⃣ HƯỚNG DẪN ĐIỀN DỮ LIỆU

### Bước 1: Thêm Logo Nguồn Tin

```sql
UPDATE public.news_sources
SET logo_url = 'https://...'
WHERE name = 'Marca';
```

### Bước 2: Thêm Logo Đội Bóng cho Fixtures

```sql
UPDATE public.fixtures
SET
  home_logo_url = 'https://...',
  away_logo_url = 'https://...'
WHERE id = 'fixture_id';
```

### Bước 3: Thêm Ảnh & Danh Hiệu cho Cầu Thủ

```sql
UPDATE public.players
SET
  image_url = 'https://...',
  honors = 'UEFA Champions League | 2 | 2022, 2024\nLa Liga | 4 | 2020, 2022, 2024, 2025'
WHERE name = 'Thibaut Courtois';
```
